# Contributing to PlacementHub AI Lab

Thank you for your interest in contributing to **PlacementHub AI Lab**! We welcome community contributions to advance AI research in campus placement engineering.

## 🤝 Code of Conduct

Please help maintain a respectful, inclusive, and professional environment for all contributors.

## 🛠️ How to Contribute

1. **Fork the Repository**: Create your feature branch from `main`.
2. **Setup Locally**: Run `npm install` to install dependencies.
3. **Coding Standards**:
   - Component names MUST use `PascalCase`.
   - Utility functions and hooks MUST use `camelCase`.
   - Maintain clean, single-responsibility components.
   - Use Tailwind CSS and Shadcn UI tokens for all styling.
4. **Test Build**: Run `npm run build` locally to ensure zero build errors or broken paths.
5. **Submit a Pull Request**: Provide a clear explanation of your changes and reference any related issues.

Thank you for building PlacementHub AI Lab with us!
