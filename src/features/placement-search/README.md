# Feature Module: POC 03 — Natural Language Placement Search Engine

## Overview
Enables natural language semantic queries across placement databases, candidate rosters, and historical recruitment drives.

## Key Functionality (Upcoming)
- Natural language query parser (e.g., "Show me pre-final year students with PyTorch and 8+ CGPA").
- Vector-indexed candidate search with instant result highlighting.
- Exportable candidate shortlist tables.
