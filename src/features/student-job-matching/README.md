# Feature Module: POC 01 — Student-Job Matching Engine

## Overview
This feature implements semantic vector matching between student skill profiles and employer job descriptions using NVIDIA NIM microservices (`NV-Embed-QA` and `Llama 3.1 70B Instruct`).

## Key Functionality (Upcoming)
- Vector embedding comparison for candidate-role compatibility.
- Explanable AI match reasoning scores with key skill alignment breakdown.
- Filterable candidate recommendations for corporate recruiters.
