========================================================================
PlacementHub AI Lab — Low-Fidelity HTML Wireframes Overview
========================================================================

Purpose:
These files are low-fidelity HTML/CSS wireframes created strictly for 
documentation, architecture presentation, and academic project submission.

They represent the structural layout, information hierarchy, and content 
organization of PlacementHub AI Lab prior to implementation using 
React 18, Vite, and Shadcn UI.

File Directory:
- index.html                      : Wireframe Hub & Overview Entry
- dashboard.html                  : Executive AI Platform Dashboard Wireframe
- poc1-student-job-matching.html  : POC 01 Student-Job Vector Matcher Wireframe
- poc2-resume-analyzer.html       : POC 02 Automated Resume ATS Evaluator Wireframe
- poc3-placement-search.html      : POC 03 Placement Natural Language Search Wireframe
- poc4-placement-copilot.html     : POC 04 Placement Copilot Assistant Wireframe
- poc5-career-coach.html          : POC 05 AI Student Career Coach Wireframe
- wireframe.css               : Pure CSS3 Shared Grayscale Wireframe Stylesheet

Technical Constraints Applied:
- Plain HTML5 and pure CSS3 only.
- Zero JavaScript, Zero React, Zero Tailwind, Zero external frameworks or libraries.
- Monochrome / Grayscale palette (White, Black, Gray placeholders).
- Structured information hierarchy suitable for UX review and documentation.
